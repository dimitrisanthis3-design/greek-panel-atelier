# Greek Panel Atelier

"Φτιάξε μια επαγγελματική web εφαρμογή στα ελληνικά για ηλεκτρολόγους, με τίτλο 'Σχεδιαστής Μονογραμμικού Πίνακα'.
Αριστερά στην οθόνη θέλω μια φόρμα επιλογών όπου ο χρήστης θα ρυθμίζει τον πίνακα:
- Τύπος παροχής (Μονοφασικός / Τριφασικός)
- Γενικός Διακόπτης (π.χ. 40Α, 63Α)
- Γενική Ασφάλεια (π.χ. 32Α, 40Α)
- Επιλογή για Ενδεικτική Λυχνία (Ναι/Όχι)
- Ρελέ Διαρροής RCD (π.χ. 2x40A 30mA, 4x40A 30mA)
- Μια λίστα όπου ο χρήστης θα πατάει '+ Προσθήκη Γραμμής' και θα διαλέγει Αμπέρ (10A, 16A, 20A, 25A), καμπύλη (B, C), περιγραφή (π.χ. Φωτισμός, Ρευματοδότες, Κουζίνα) και διατομή καλωδίου (π.χ. 3x1.5, 3x2.5).

Δεξιά στην οθόνη θέλω να σχεδιάζεται ΖΩΝΤΑΝΑ το μονογραμμικό διάγραμμα σε καθαρό SVG με πρότυπα σύμβολα IEC, πλαίσιο πίνακα και ονομασίες.
Πάνω από το σχέδιο βάλε δύο κουμπιά: 'Λήψη SVG' (για άνοιγμα σε CAD/Illustrator) και 'Εκτύπωση / Αποθήκευση PDF'."
